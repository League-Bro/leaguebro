Your runes, timers and builds, without the ads.

League Bro sets up champ select for you, scouts the lobby, and keeps a small overlay of objective timers and your next item in game. Free, no account, nothing to sign up for.

Help at every point of a game

It works in the background while League runs, and only shows up when there's something useful to show.

Any time

Look up any champion

Runes, spells, skill order and the full build for every champion and role, from OP.GG's ranked stats, with a short reason for each pick.

Champ select

Set up when you lock in

Your rune page, summoner spells and in-game shop build are set the moment you lock in. Flash stays on the key you use, and your own pages are never touched.

In game

A small overlay

Dragon, Baron and inhibitor timers, which ability to level next, and the next two items you can buy. Clicks go straight through it to the game.

After the game

See how it went

Damage, gold, vision and CS for all ten players, plus the latest patch notes sorted into buffs and nerfs.

What it leaves out

  • No ads, no account, no tracking, and nothing running when League isn't.
  • It never reads game memory, injects into the game or presses keys for you.
  • No enemy cooldown or ultimate timers, and no hidden names in ranked champ select. Riot doesn't allow them, so neither do we.

Install in a minute

After this, League Bro updates itself. You'll see a banner when there's a new version.

  1. Download and run it

    Run the installer you downloaded. It installs for your Windows account only, so it doesn't ask for admin rights.

  2. Allow it past SmartScreen

    League Bro isn't code-signed yet, so Windows warns about it the first time. Click More info, then Run anyway.

Questions

If yours isn't here, open an issue on GitHub.

Can I get banned for using it?

League Bro works the same way as well-known companion apps. It only uses the League client's own local interface and Riot's official in-game data, and it skips the features Riot has banned, like enemy ultimate timers.

It isn't registered with Riot, though, and nobody but Riot can promise anything about bans. You use it at your own risk.

Why does Windows say it's unrecognized?

Windows trusts apps that are signed with a paid certificate and downloaded by lots of people. League Bro isn't signed yet. The installer is built from the public source code on GitHub, so you can see exactly what's in it.

The overlay doesn't show in game

Set League's Window Mode to Borderless or Windowed. Fullscreen draws over every other window. Also check that "Show the in-game overlay" is on in League Bro's Settings.

How do I move the overlay?

Click the padlock in the overlay's top-right corner, drag it where you want it, then click the padlock again to lock it in place.

Where do the recommendations come from?

OP.GG's ranked stats for your champion and role. If you've saved your own rune page or build for a champion, yours always comes first. For rare picks without enough games, it uses the League client's own suggestion.

I had League Buddy installed

League Buddy is the old name. Install League Bro, then uninstall League Buddy from Windows Settings, Apps, Installed apps, so only one copy manages your rune page. In the League client, delete the leftover "League Buddy" rune page and item set.

How do I uninstall it?

Windows Settings, Apps, Installed apps, League Bro, Uninstall.
